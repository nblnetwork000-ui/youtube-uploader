Privacy Policy — YouTube Upload Automation Tool

Last updated: November 20, 2026

This tool is a personal automation utility operated by L.EVER ("the Operator") and used exclusively by the Operator to upload videos to the Operator's own YouTube channels. It is not offered to the public and has no other users.

Data accessed

Through the YouTube Data API v3, the tool accesses only the ability to upload videos and set metadata and thumbnails on the Operator's own channels, using the youtube.upload scope. The tool does not access data about viewers, subscribers, comments, or any other channels.

How data is used

OAuth refresh tokens for the Operator's own channels are stored in a local file on the Operator's own computer and are used solely to authenticate upload requests made by the tool on the Operator's instruction. No Google user data is transmitted to any server operated by the Operator or any third party, other than to Google's own API endpoints for the purpose of the upload itself.

Storage, retention, and deletion

Refresh tokens are retained only on the Operator's local computer for as long as the tool is in use. Deleting the local token file, or revoking the tool's access from the Google Account permissions page (https://myaccount.google.com/permissions), permanently removes the tool's access. No other Google user data is stored.

Sharing

No data obtained through Google APIs is sold, shared, or disclosed to any third party, and it is not used for advertising or analytics.
